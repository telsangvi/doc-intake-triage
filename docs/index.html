What We Built

document intake triage · a forward-deployed AI engineer practice project

In one line: a public-benefits office gets piles of messy documents. This system reads each one, pulls out the important fields, checks what's missing, finds the policy rule that applies, and tells a human what to do next — automatically route it, send it back, or take a closer look. It never decides who gets benefits.

Readables

Project brief

The plan document, written as an engagement: the customer, the metrics, the risks, the demo script.

Nothing needs an API key. The whole project runs offline with a stand-in model and a stand-in embedder, so you can develop without spending anything or touching a real account. Swapping in a real model or a real embedder is a config change, not a rewrite.
