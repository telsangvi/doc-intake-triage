# Policy 3.1 — Identity Verification

## 3.1(a) Requirement
Each case must contain one government-issued identity document showing the
applicant's full name and a unique identifier.

## 3.1(b) Name consistency
The name on the identity document must match the name on the application. A
mismatch, or an illegible name, requires human review before the case proceeds.

## 3.1(c) Expired documents
An expired identity document is acceptable only if it was issued within the
last five years.
